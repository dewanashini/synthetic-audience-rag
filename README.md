# Synthetic Audience RAG

A Retrieval-Augmented Generation (RAG) system designed to simulate how a defined target audience might respond to products, ideas, and content.

## Overview

This project combines audience research, vector retrieval, and large language models to generate evidence-grounded synthetic audience responses.

## Planned Pipeline

Audience Data
→ Document Processing
→ Embeddings
→ Vector Database
→ Retrieval
→ LLM
→ Synthetic Audience Response

## Project Goals

- Build a structured synthetic audience knowledge base
- Implement a RAG pipeline for audience-specific retrieval
- Generate grounded audience responses
- Evaluate retrieval quality
- Explore how synthetic audiences can support early-stage product research
